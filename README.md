Lumen Grove is an original lantern-garden tower-defense game: guard the Heart Lantern at the center of the garden from 10 waves of shadow wisps. Plant light-blooms on soil plots — Ember (fast bolts), Frost (slows wisps), Sun (heavy splash) — earn sunpetals for every banish, and survive all 10 waves to win.

## Run it

Open `game/index.html` in a desktop browser, or serve the `game/` folder with any static server. No build step, no network requests. Controls: mouse to plant/sell, 1/2/3 to choose a bloom, Space for next wave, P pause, R restart, M mute.
